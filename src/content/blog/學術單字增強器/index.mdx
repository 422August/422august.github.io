由於在清華大學參加資工微課程時，教授要求我們製作一個能夠增強學術單字學習的工具，於是我便開始著手開發這個專案。這個工具主要的功能是把未經學術化的單字，轉換為在 Academic Keywords List 中所列出的學術單字，利用 Gemini API 調用 2.5-flash 模型完成。
<ArticleCard slug="清華大學微課程" />

## 發想
在獲得目標後，我便開始進行了網站分析，我們必須有一個用以輸入API Key的欄位，以及需轉換文字的欄位，並且在轉換後能夠顯示結果。除此之外，我們還需要一個按鈕來觸發轉換的動作。

首先，我們需要一個輸入欄位來讓使用者輸入他們的 API Key。這個欄位應該是安全的，並且能夠隱藏使用者的輸入，以保護他們的隱私。

## 過程
在設計過程中，因為我始終認為 UI/UX 非常重要，所以我花了不少時間在設計上，確保使用者能夠輕鬆地使用這個工具。在設計prompt時，我必須讓Gemini API能夠理解我們的需求，並且能夠正確地將未經學術化的單字轉換為學術單字。並且須以固定格式傳回，才能使用regex解析。
