因為透過 GitHub Student Developer Pack 拿到了 `.tech` 網域，加上先前已經用 Astro + GitHub Pages 架好個人部落格，便決定把部落格搬到這個自訂網域下。於是就有了這篇文章。

## Astro + GitHub Pages 部署
{/* <CaptionImage name="cover.jpg" alt="這是第二張圖片的說明" /> */}
我直接選用 Astro 模板，複製專案後進行部署。整體過程並不複雜，只需要微調幾個元件即可。

## DNS 設定

最初是在 get.tech 申請網域，原本打算直接透過 GitHub 進行部署，不依賴其他第三方服務。然而，無論怎麼設定 A 紀錄與 CNAME，DNS 驗證總是無法通過，讓人相當沮喪。最後我決定改用 Vercel 來託管部署，並將網域的 Name Server 指向 Vercel，問題立刻順利解決。目前將網站部署在子網域（三級網域）上，而主網域（二級網域）則直接設定重定向至子網域。

## 心得反思

我必須承認，這是我第一次接觸 DNS 設定，像是 A 紀錄、AAAA 紀錄、CNAME 等概念。過程確實有些吃力，剛開始問 AI 也沒有得到很明確的解法，反而越改越混亂。好在後來 AI 建議嘗試第三方部署服務，雖然起初有點排斥依賴第三方平台，但嘗試之後發現運作得非常順暢，也便利許多。雖然這個網域只有免費提供一年，不過到期後我大概也會想繼續續費使用。
